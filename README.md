# Network Words（ネットワーク用語）

ネットワークの授業（レイヤー1・2）の用語を、11言語で学ぶアプリ。 https://tomo0916.github.io/network/

意味は自分の言語で理解し、用語は日本語で覚える。用語一覧・単語カード・4択クイズ（ミックス・場面問題・数字と順番・聞き取り。問題数10/20/40）・仕分けクイズ・復習・動く図解
（減衰とリピーター、ハブとスイッチ、ユニキャスト等、イーサネットフレーム、CSMA/CD、ネットワーク部とホスト部、ARP、ルーティングとTTL）がある。図解は「自動再生」で最後まで流れ、速さ（×0.5／×1／×2）を変えられる。用語は読み上げボタンで日本語の音声を聞ける。
構成と言語の仕組みは [SQL Practice](https://github.com/Tomo0916/sql-practice) の `next/` と同じ。

## 授業での使い方

**先生用ページ** `…/network/teacher.html`（提示・リンク・紙テストはログイン不要。クラスだけ SQL Practice と同じ先生アカウントでログイン）

| タブ | できること |
|---|---|
| 提示 | 1語ずつ大きく映す。用語→説明、説明→用語のどちらを先に見せるか選べる。← → で移動、スペースで答え |
| リンクを配る | 範囲・ページ・言語を選ぶと、生徒用のリンクとQRコードができる。QRは全画面で大きく出せる |
| 紙テスト | 範囲・問題数・形式（用語を書く／4択／場面問題／数字と順番）・説明の言語・バージョン（A〜D）を選び、印刷またはPDF保存。最後のページが解答 |

**アドレスで直接指定する**

| やりたいこと | アドレス |
|---|---|
| 今日の範囲だけを配る | `…/network/?range=lesson-13`（`ch-2` `L1` `g-signal` なども使える） |
| 言語を指定して開く | `…/network/?lang=vi` |
| スクリーンに映す（文字を大きく） | `…/network/?present=1`、または 設定 → 発表モード |
| 図解を直接開く | `…/network/#/demos/hubswitch`（`cast` `csmacd`） |

- 学習の記録（覚えた用語・間違えた用語・正答数）は、生徒の端末のブラウザの中だけに保存される。名前などは扱わない。
- クイズ画面の「自動で次へ」スイッチをオンにすると、答えたあと自動で次の問題に進む（正解は約2秒、不正解は説明を読めるよう約5秒）。
- クイズで間違えた用語は「復習」に入り、1日後・3日後・7日後にもう一度出る。
- 一度開けば、Wi-Fiがなくても動く。ホーム画面に追加できる。

## クラス機能（SQL Practice と同じ Supabase）

| 先生（`teacher.html#/class`） | 生徒 |
|---|---|
| クラスを作る → クラスコードとQRが出る | QRを読む（`…/network/?class=コード`）か、ホームの「クラスに参加する」でコードを入れる |
| 課題を決める：範囲・出題（ミックス／場面／数字と順番）・問題数 → 「保存して生徒に配る」 | ホームとメニュー（旗のマーク）に課題が出る |
| 「授業ライブ」45・50・90分を押す | 生徒の画面に課題が自動で開く。ほかの画面では赤い帯「課題にもどる」 |
| ライブ表：生徒×問題の○×が届いたそばから入る。下の行は問題ごとの正答率。「名前をかくす」でスクリーンに映せる | ニックネーム＋4けたの番号で参加。別の端末でも同じニックネームと番号で続きから |
| 生徒の一覧：新しい番号を出す・外す | 課題の途中で閉じても、続きの問題から再開 |

| クイックテスト：範囲・出題・問題数・制限時間（なし／3／5／10分）を決めて「始める」 | 10秒のカウントダウンのあと、全員の画面で同時に始まる。途中で答えは出ず、最後に○×と正解 |
| ライブ表の切りかえ：課題／実施中のクイックテスト／過去のクイックテスト | |
| 「よくある間違いを映す」：正答率の低い問題から、選択肢ごとに何人選んだかを棒グラフで（名前は出ない）。スペースキーで正解を表示、←→で次の問題。表の問題番号を押すとその問題 | |
| クラスの苦手な用語：すべての答えから正答率の低い10語 | |

- 同じ「セット」なら全員に同じ問題が同じ順番で出る（ライブ表の列が問題番号になる）。「問題を入れかえる」で新しいセット。
- 課題以外のクイズ・復習の答えも、クラスに入っている間は先生に届く（あとで「よく間違える用語」の集計に使う）。
- 記録はニックネームと答えだけ。番号は暗号化して保存し、先生にも見えない。
- **学習の記録（覚えた用語・復習・正答率・読んだ回・クイックテストの結果）もクラスに保存される**（`net_progress`）。別のPCやスマホで同じニックネームと番号で「続きから」入ると続きができる。
- 共用のPCでは、使い終わったら「クラス」→「この端末からログアウト」。その端末の記録は消え、クラスには残る（「クラスを抜ける」はクラスの記録も消える）。
- クイックテストの結果画面とクイックテストのページから、まちがえた問題の復習・同じテストへの再チャレンジができる（練習の答えは先生に届かない）。

**Supabase の設定（最初に1回、アプリを更新したときにもう一度）**
1. Supabase の SQL Editor に `supabase/network.sql` を全部貼って Run（何度実行しても安全）。
   続けて `supabase/network-progress.sql` も Run（学習記録の保存。2026年11月に追加）。
2. 先生のアカウントと先生リスト（`teachers`）は SQL Practice と共通。SQL Practice で登録済みの先生はそのまま使える。
3. `config.js` は SQL Practice と同じ接続先。

SQL Practice のテーブル（`classes`・`members`・`attempts`）には一切さわらない。ネットワーク用語のクラスは `net_classes`・`net_members`・`net_member_pins`・`net_attempts` に入る。クラスコードは両方のアプリで重ならないように作られる。

## 用語を増やすには

| やりたいこと | 編集するファイル |
|---|---|
| 用語を足す | `js/words.js` に1行（idは英小文字、一度決めたら変えない） |
| 用語の説明・たとえ | `i18n/ja.js`・`easy.js`・`en.js` の `w.<id>.desc` と `w.<id>.tip` |
| 場面問題を足す | `js/scenes.js` に1行（正解の用語と、間違いの選択肢3つ）＋ `i18n/*.js` の `s.<id>` |
| 数字・順番の問題を足す | `js/facts.js` に1行（最初の選択肢が正解）＋ `i18n/*.js` の `f.<id>` |
| グループ・授業回・図解 | `js/groups.js` |
| 図解を足す | `js/demos/<id>.js` を作り、`js/groups.js` の `DEMOS` と `sw.js` に追加 |
| 画面の文言・翻訳を直す | `i18n/<言語>.js`（1言語1ファイル。やさしい日本語は `{漢字|かんじ}` でふりがな） |
| 解説ページ（テキスト）を足す | `js/lessons.js` にページの組み立て、図は `js/figures.js`、文章は `text/<言語>/<回>.js`（`ls.<回>.*`）、図の中の文字は `text/<言語>/fig.js`（`fg.*`） |

日本語（`ja`）を元の文章として書き、`easy`・`en` とほかの8言語は Claude（AI）が翻訳する。訳がまだない文言は英語で表示される。
どの言語で何が足りないかは `node tools/missing.mjs`（1言語分を原文つきで出すなら `node tools/missing.mjs vi`）。

解説の文章は回ごとのファイルなので、開いた回の分だけ読み込まれる（44回分になってもアプリは重くならない）。

ミャンマー語は Unicode で書く（Zawgyi は使わない）。

変更したら必ずチェックを実行する（npm install は不要）:

```
node tools/check.mjs
```

用語のid・グループ・紛らわしい用語の参照先、全言語の抜けと `{placeholder}` の一致、ほかの言語への日本語の混入、
やさしい日本語のふりがな漏れ、画面で使う文言の有無、4択の選択肢が必ず4つ作れることを調べる。
✗（エラー）は直す。!（警告）は、まだ翻訳していない言語などで、公開してよい。

公開後に大きく変えたときは `sw.js` の `VERSION` を1つ上げる（オフライン用キャッシュの更新）。

```
index.html                 生徒用アプリ
css/app.css                デザイン（SQL Practice と共通部分＋ネットワーク用）
teacher.html               先生用ページ
js/student.js              生徒用の画面（ホーム・テキストと回ごとのページ・用語・練習・図解・クラス）
js/lessons.js              解説ページの組み立て（回ごと）
js/figures.js              解説ページの図
js/teacher.js              先生用の画面（提示・リンクとQR・紙テスト）
js/common.js               両方で使う部品（用語の表示・読み上げ）
vendor/qrcode.js           QRコード（SQL Practice と同じもの）
js/words.js                用語の骨組み（増えていく）
js/backend.js              クラス機能（Supabase。SQL Practice と共有）
supabase/network.sql       クラス機能のテーブル（Supabase の SQL Editor で実行）
supabase/network-progress.sql  学習記録の保存（network.sql のあとに実行）
js/scenes.js               場面問題（「こんなとき、どの用語？」）
js/facts.js                数字・順番の問題（ビット数、長さ、フレームの順番など）
js/groups.js               レイヤー・グループ・授業回・図解の一覧
js/quiz.js                 範囲と出題（画面のコードなし）
js/store.js                学習記録の保存（このブラウザ。クラスに入っていればクラスにも）
js/i18n.js, js/ui.js       言語の読み込み・共通部品（SQL Practice と同じ）
js/demos/                  図解アニメーション（1図解1ファイル）
i18n/                      画面の文言：ja / easy / en / ne / fr / my / bn / si / id / vi / zh
text/<言語>/               解説ページの文章（回ごと）と図の文字（fig.js）
tools/check.mjs            自動チェック
tools/missing.mjs          翻訳の抜けを一覧にする
sw.js, manifest.webmanifest, icons/   オフライン対応・ホーム画面に追加
```
